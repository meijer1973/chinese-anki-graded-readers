Use this file for durable fantasy rules, costs, limits, and links between mechanisms. Keep `series_bible.md` compact; put mechanism detail here.

## Series-Level Rules

- Each story should use one primary impossible mechanism, repeated enough to become clear.
- Fantasy clues may guide 林安's reporting, but they are not publishable legal proof by themselves.
- Every mechanism should create a choice: protect a source, verify evidence, publish carefully, or refuse managed truth.
- New mechanisms should connect to the larger record / memory pressure only a little at a time.
- Do not add a new magic system when an existing mechanism or variant can do the job.
