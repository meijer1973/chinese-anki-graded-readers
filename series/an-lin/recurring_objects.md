# 林安 Recurring Objects

## Approved Recurring Fantasy Objects

- 雨票
- 黑票
- 灵灯

## Approved Recurring Evidence Objects

- 文件
- 资料
- 档案
- 录音
- 录像
- 照片
- 密码

## Object Guidance

Objects should create choices. A file should not only be found; it should force 林安 to decide whether to protect a source, confirm a fact, or publish a dangerous article.
