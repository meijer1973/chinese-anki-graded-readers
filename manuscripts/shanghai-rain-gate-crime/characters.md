# Characters

- 林安 — 记者. Wants the truth but must learn that not every truth can be reported in the same way.
- 陈雨 — 警察. Wants usable evidence and a lawful path through an impossible case.
- 老马 — 书店老板 / 守门人. Failed under pressure but chooses repair.
- 许白 — 摄影师. Hid the package and becomes the voice clue.
- 宋文 — 经理 / 老板. Uses 影门 as a crime tool.
- 阿海 — 快递员. Missing witness and moral trigger for the plot.
- 小周 — 保安. Frightened accomplice who later helps.
- 老刘 — 司机师傅. Provides ordinary-world witness evidence.
