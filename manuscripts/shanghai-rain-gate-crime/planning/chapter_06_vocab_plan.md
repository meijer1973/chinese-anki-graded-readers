# Chapter 06 Vocabulary Plan

## Chapter purpose
Shift from people to documents.

## Scene goal
林安 obtains a file that changes the case.

## Conflict
Publishing the file could expose a source.

## Emotional turn
Truth becomes ethically difficult.

## Case function
Evidence discovery.

## Journalist function
Protect source and check file origin.

## Fantasy function
The file reacts to rain and light.

## Learning function
Repeat: 文件, 来源, 保密, 资料, 白光.

## Main locations
Office, file room, rainy street.

## Characters and roles
林安: journalist. Source: hidden helper. Editor: pressure.

## Core known words to reuse
文件, 秘密, 保护, 帮, 给, 拿, 打开.

## Stretch words to introduce
- 来源: source/origin.
- 保密: source-protection action.
- 资料: research material.

## Stretch words to repeat from earlier chapters
确认, 动机, 雨票, 影门.

## Risky unavailable concepts to avoid
Complex data or computer jargon.

## Chapter hook
A file page shows the same mark as the shadow door.

## End-of-chapter change
林安 chooses not to publish immediately.
